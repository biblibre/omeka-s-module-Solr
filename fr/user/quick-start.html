Quick start

  1. Install the Search module

  2. Install this module

  3. In the administration menu, click on « Solr »

  4. Edit the default node and set the URI of your Solr collection/core and type dcterms_title_txt in « Query fields (qf) »

  5. In Search admin pages:

    1. Add a new index using the Solr adapter

    2. Launch the indexation by clicking on the « reindex » button (two arrows forming a circle)

    3. Add a page using the created index

    4. In page configuration, you can enable/disable facet and sort fields (more fields can be created by going to the Solr admin page)

  6. In your site configuration, add a navigation link to the search page

  7. Go to your site, then click on the navigation link you just added.

  8. The search form should appear. Type some text then submit the form to display the results.
